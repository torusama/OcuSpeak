# Design Research References

The implementation is original. The following official products and resources were reviewed only to understand common AAC, gaze-access and child-learning interaction patterns.

## Cboard AAC

- Official help: https://www.cboard.io/help/
- Official product site: https://www.cboard.io/en/

Useful patterns reviewed: symbol-and-text communication boards, text-to-speech, configurable display, cross-device web access and board management.

## Smartbox Grid and eye gaze

- Grid/Smartbox downloads: https://thinksmartbox.com/downloads/
- Eye gaze overview: https://thinksmartbox.com/eye-gaze/
- Look to Learn: https://thinksmartbox.com/look-to-learn/

Useful patterns reviewed: calibration guidance, stable gaze targets, multiple access methods and clear separation between communication and setup tools.

## Tobii Dynavox TD Snap

- Product page: https://www.tobiidynavox.com/products/td-snap/

Useful patterns reviewed: flexible AAC page sets, caregiver/family customization and predictable navigation.

## Khan Academy Kids

- Official site: https://learn.khanacademy.org/khan-academy-kids/

Useful patterns reviewed: rounded, low-anxiety visual language, large visual choices, concise instructions and child-friendly progress feedback.

## Project-specific adaptation

OcuSpeak does not copy layouts, assets or proprietary page sets. It adapts broad interaction lessons to the project's own constraints:

- Exactly four stable Patient targets per page by default.
- A gaze-friendly next-page target instead of continuous scrolling.
- Manual input and offline fallback alongside gaze.
- Manual SOS always visible and independent from camera AI.
- Caregiver editing and analytics separated from the Patient interface.
- OcuSpeak palette, typography and original Lucide-based icon treatment.
